About compatibility

Anthropic Claude uses a billed API key and always calls https://api.anthropic.com, never this listener. ChatGPT and Copilot use a Switchboard device sign-in. Antigravity uses the local agy Keychain login through an unofficial Cloud Code adapter. Grok Build uses the local grok login session against the CLI chat proxy. Other coding agents should use the OpenAI-compatible base URL and the gateway API key. Anthropic does not support routing Claude Code to non-Claude models. A catalog list is not the same as access; use Scan access before trusting a Copilot Claude id.
